## Запуск приложения в Docker
1. docker-compose up

---

## Запуск сервера локально
1. docker-compose up
2. docker stop <контейнер books>
3. cd books_server
4. npm i
5. npm run dev

---

## Запуск клиента локально
1. docker-compose up
2. docker stop <контейнер books_client>
3. cd books_client
4. npm i
5. vite dev
